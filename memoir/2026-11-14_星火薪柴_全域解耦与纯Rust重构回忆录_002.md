## 零、 认知质变：从“大泥球拼合”到“冷热解耦”

在今日早先的探索中，我们曾将 Live2D 桌宠、任务拓扑、文件监听与具体的短剧工具（`omni`、`baocut`、`cutcli`）强行焊死在同一个进程与代码库中。

用户敏锐地提出了决定系统生死的灵魂拷问：
> *“合的太彻底了，需要拆出来，并建立框架连接对吗？合到一起之后，启动也费时间，也浪费冷热解耦，需要做到低耦合，高内聚对吗？”*

由此，拉开了一场系统级的**大师会诊与手术重构**。

## 一、 四大大师药方与开源神刀（理论底座）

为了不再盲目写代码，我们深挖现代 AI 工业界与计算机史上的四位顶尖宗师：

1. **Joe Armstrong（Erlang 之父）——「任其崩溃与信箱隔离」**：
   - 业务是业务，桌宠是桌宠，互不持有内存指针。短剧转写跑崩溃一万次，桌宠依然优雅待命。
2. **Martin Kleppmann（《DDIA》作者）——「事件溯源与物化视图」**：
   - 真实世界没有原地状态修改，只有追加事件流。星婉桌宠的本质，根本不是控制器，而是事件流在屏幕上的**“物化视图（Materialized View）”**。
3. **Fabrice Bellard（FFmpeg 之父）——「Unix 滤镜流隔离」**：
   - `baocut` 专职音频，`cutcli` 专职草稿。Rust 核心只做管道编排，绝不将庞大的 C/C++ 音视频库静态死锁在主系统中。
4. **Goose 架构组 (Linux基金会) & ComfyUI ——「无头图执行器 + 遥测流观察者」**：
   - 后台是纯无头的自愈循环状态图（Headless StateGraph），前端只是连上来收 `NodeEntered`、`ProgressUpdate`、`AwaitingApproval` 的轻量观察者。

## 二、 东方哲学注入：「星火与薪柴」世界观

系统正式定名为 **【星火】**，并确立了三元宇宙运转法则：

* 🪵 **木（薪柴 / 能量流）**：
  - **生木（静态数据）**：原著小说、剧情大纲、分镜矩阵、干音物料。
  - **引信（动态事件）**：用户的目标输入、Linux Inotify 捕获的代码与剧本保存事件。
* 🌋 **炉（炉膛 / 算力底座）**：
  - **`drama-worker`（纯 Rust 冷端无头引擎）**。隔热严密，无论内部并发多凶猛，绝不波及外界。
* 🐉 **火（星火 / 具身生命）**：
  - **`agent-mascot`（星婉桌宠）**。火随薪动：
    - `IdleBreath`：暗火温存，0% CPU 极低能耗待命；
    - `ThinkingPondering`：火苗窜升，烘烤分析原著拓扑；
    - `WorkingFocused`：烈火烹油，并发调度工具合龙；
    - `ExcitedCheering`：火树银花，全流程大圆满交付！

## 三、 手术动刀实录（Pure Rust 工业级改造）

### 1. 创立标准信标协议：MSP v1.0
- 文件位置：[`src/protocol.rs`](file:///home/daoxuan/Projects/AgentMascotWorkstation/src/protocol.rs)
- 规范落地：`~/.config/agent-mascot/runtime_state.json`
- **Linux 内核级原子写入**：
  采用 `tempfile` + `fs::rename` 原子替换机制，读取端永远只能读到完整的新版本或旧版本，从物理底层杜绝“脏读半截 JSON”导致的 Panic。

### 2. 剥离无头业务执行器：`drama-worker` (冷端)
- 文件位置：[`src/bin/drama_worker.rs`](file:///home/daoxuan/Projects/AgentMascotWorkstation/src/bin/drama_worker.rs)
- 体积：**1.5 MB** 纯静态二进制
- 职责：独占 DAG 任务拆解与 `omni`、`baocut`、`cutcli` 真实并发调度，每一步通过 `BeaconEmitter` 发射遥测心跳，执行完自动释放算力。

### 3. 瘦身桌宠观察者：`agent-mascot` (热端)
- 文件位置：[`src/bin/agent_mascot.rs`](file:///home/daoxuan/Projects/AgentMascotWorkstation/src/bin/agent_mascot.rs)
- 体积：**1.1 MB** 纯静态二进制
- 职责：彻底切除所有业务脏活。利用 Inotify 阻塞监听，**0% CPU 占用**，毫秒级响应，将信标解析为精美的终端彩色仪表盘并同步至 60FPS Web 视图。
